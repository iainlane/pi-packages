The `codex` reviewer can use shell and read tools in a fresh read-only copy of a routed command's destination with networking denied. A review of a private Docker workspace sees its current edits. The reviewer opens the copy on its first investigation call and closes it when the review ends. Each review can make eight calls and receive 64 KiB of output. The footer reports whether any tools have investigation routes. Unrouted requests and unavailable copies use transcript-only review. Pi 1.5 is now required. The pinned BYOS SDK is included in the package archive, so installation does not need to fetch its Git dependency. BYOS provider extensions activate themselves and supply their configuration and base policy through a callback.
