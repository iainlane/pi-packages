The `codex` reviewer can use shell and read tools in a fresh read-only copy of a routed command's destination with networking denied. A review of a private Docker workspace sees its current edits. The reviewer opens the copy on its first investigation call and attempts to close it when the review ends. If cleanup is unconfirmed, the decision log includes the failures and any recovery details. Each review can make eight calls and receive 64 KiB of output. The footer and `/auto-stats` show the most recent investigation outcome. Unrouted requests and unavailable copies use transcript-only review. Pi 1.5 is now required. The pinned BYOS SDK is included in the package archive, so installation does not need to fetch its Git dependency. BYOS provider extensions activate themselves and supply their configuration and base policy through a callback.
